# PWA Hello World

A minimal Progressive Web App demonstrating the three core mechanics:

1. **Manifest** (`manifest.webmanifest`) — identity + installability
2. **Service worker** (`sw.js`) — offline via request interception
3. **Secure context** — required for the above (HTTPS, or `localhost` for dev)

Everything is commented to teach. See **RUN.md** for how to run it and what
to observe (DevTools Application tab, offline reload, install to home screen).
