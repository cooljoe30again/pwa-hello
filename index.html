PWA Hello World

Network: online

Launch mode: browser tab

The three mechanics

  1. Manifest (manifest.webmanifest) — the app's ID card: name, icons, colors, "launch me standalone."
  2. Service worker (sw.js) — a script the browser runs in the background, even with no page open. Ours intercepts network requests and serves cached files, so the app works offline.
  3. Secure context — the browser only grants these powers over HTTPS (or localhost, which counts as secure for development).

Try this

  1. Open DevTools → Application tab: see the Manifest, the registered Service Worker, and Cache Storage.
  2. DevTools → Network tab → set Offline, then reload. The page still loads — that's the service worker serving the cache.
  3. Chrome menu → "Install PWA Hello" (or the install icon in the address bar). It launches without browser chrome, and the "Launch mode" badge above flips to standalone.
